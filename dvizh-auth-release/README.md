# ДВИЖ — собственный вход по логину и паролю

Отдельный authentication gateway для существующего ДВИЖа.

## Архитектура

- текущий backend ДВИЖа остаётся на `127.0.0.1:8000`;
- gateway запускается на `127.0.0.1:8002`;
- после входа gateway проксирует приложение и API, подставляя один стабильный локальный user ID;
- Telegram bridge читает тот же ID из `/var/lib/dvizh/auth-identity.json`;
- существующие данные можно перенести автоматически по маркерной задаче `Проверка связи`;
- до проверки основная точка входа exe.dev не переключается.

## Безопасность

- пароль хранится как `scrypt`-хеш с отдельной солью;
- raw session token в базе не хранится — только SHA-256;
- cookies: `Secure`, `HttpOnly`, `SameSite=Lax`;
- CSRF-защита для входа, первичной настройки, выхода и смены пароля;
- ограничение попыток входа;
- регистрация закрывается после создания первого аккаунта;
- setup выполняется по одноразовому коду;
- заголовки пользовательской идентичности от клиента удаляются и заменяются сервером.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/Itosyro/voice-bot/codex/dvizh-auth-gateway-2026-08-29/install-dvizh-auth.sh | bash
```

После установки терминал покажет приватный setup URL и одноразовый код. Логин и пароль задаются только на странице самого ДВИЖа и не передаются разработчику.
