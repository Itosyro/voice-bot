# ДВИЖ — недельный график v1

Телефонный слой недельного расписания для Telegram-компаньона ДВИЖа.

## Что входит

- `📅 Сегодня` объединяет повторяющиеся задачи и блоки расписания.
- `🗓 Неделя` показывает ближайшие 7 дней.
- `➕ Событие` создаёт разовый или еженедельный блок.
- `🗂 Расписание` показывает все правила расписания.
- Категории: работа, отдых, встреча, дела, документы, здоровье, зал, волейбол, разное.
- Напоминания: в момент начала, за 10/30/60/120 минут.
- После напоминания можно отметить блок, пропустить только этот раз или отложить на 10/30 минут.
- Старые незакрытые блоки не превращаются в очередь просроченных долгов: они автоматически закрываются как пропущенные.
- Используются текущие часовой пояс и тихие часы Telegram-ДВИЖа.
- Существующие задачи, чек-ины, «Я залип», auth gateway и web bridge не заменяются.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/Itosyro/voice-bot/codex/dvizh-weekly-schedule-v1-2026-08-29/install-dvizh-weekly.sh | bash
```

Установщик сначала делает SQLite backup и копии изменяемых модулей. При ошибке runtime-файлы Telegram-бота откатываются автоматически.

## Следом

После живой проверки этот же schedule-слой будет выведен в веб-ДВИЖ. На его основе дальше строятся Upper/Lower 4× в неделю, отдельные волейбольные тренировки с recovery-оценкой, напоминания по документам/записям и остальные блоки roadmap.
