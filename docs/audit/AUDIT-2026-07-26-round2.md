## 1. Проверка слуха «Telegram поднял лимит до 30–40k символов»

**НЕ ПОДТВЕРДИЛОСЬ.** Проверено по споке Bot API 10.2 (14 июля 2026):
`sendMessage.text` — по-прежнему **1–4096 символов** (UTF-16), caption — 1024.
Вероятный источник слуха — **Rich Messages** из Bot API 10.1 (июнь 2026):
отдельный тип «документо-подобного» контента (`sendRichMessage`) с таблицами,
код-блоками и сворачиваемыми секциями, без объявленного символьного лимита.

**Что реально нового в Bot API 2026 и что мы взяли:**
| Версия | Что | Статус у нас |
|---|---|---|
| 9.4 (фев) | Цветные кнопки `style=` | ✅ давно используем |
| 9.5 (мар) | `sendMessageDraft` (стриминг-превью) открыт всем ботам | ✅ внедрён опт-ин `ENABLE_DRAFT_STREAMING` (по умолчанию выкл — грабли №1) |
| 10.1 (июн) | Rich Messages | 🔜 кандидат для длинных ответов (роадмап) |
| 10.2 (июл) | Ephemeral messages, rich-блоки | — пока не нужно |
| — | `<blockquote expandable>` | ✅ многочастные ответы теперь свёрнуты |

aiogram поднят до >=3.30 (поддержка Bot API 10.2).

## 2. Свежее исследование провайдеров (детали в отчёте раунда 1 + новое)

Ключевые актуальные цифры (июль 2026):
- **Groq free**: gpt-oss-120b — 30 RPM / 1000 RPD / **8K TPM / 200K токенов в день**;
  Whisper — 20 RPM / 2000 RPD / **8 часов аудио в день**. Депрекации продолжаются,
  Groq консолидируется на gpt-oss (наша модель — «выживший», менять не надо).
- **Критичное открытие**: 8K TPM означает, что **транскрипт длиннее ~25 минут
  раньше вообще не мог обработаться LLM** (413). Теперь такие запросы роутятся
  в OpenRouter `openai/gpt-oss-120b:free` (контекст 131K) при заданном ключе.
- **Cerebras free**: 1M токенов/день, тот же gpt-oss-120b, скорость 700–1700 t/s,
  но контекст ~8K и каталог free-моделей сжимается. Подключён как первый фолбэк.
- **SambaNova Whisper — мёртв** (исчез из каталога в 2026) — вычеркнут из планов.
- STT-фолбэки при исчерпании 8ч/день: Cloudflare Workers AI whisper-v3-turbo
  (~3.5 ч/день, REST) или Gemini (аудио→токены). Пока не внедрены (нужны ключи).
- **Итог: с Groq НЕ уходим** — обвязали фолбэками. Владельцу стоит завести
  бесплатные ключи `CEREBRAS_API_KEY` и `OPENROUTER_API_KEY` (см. .env.example);
  разовая покупка $10 на OpenRouter даёт 1000 бесплатных запросов/день навсегда.

## 4. Что улучшено для сценария «много голосовых каждый день»
1. Первое сообщение нового юзера сразу обрабатывается (дефолт-полировка).
2. «Другой режим» = мгновенный повторный прогон без пересылки.
3. «Транскрипт» — что я сказал дословно, бесплатно (без второго Whisper).
4. Часовые голосовые: быстрая нарезка (copy-кодек), параллельный Whisper,
   выжившие чанки не теряются, длинный транскрипт уходит в OpenRouter.
5. Результат больше никогда не затирается кнопками и не теряется на эмодзи.

## 5. Урок процесса (в копилку граблей)
Проверка `ruff check . | tail` **маскирует exit-код** (pipe возвращает статус
tail) — из-за этого красный линт уехал в main. Проверять коды напрямую:
`ruff check .; echo $?` или без пайпа. Занесено в CLAUDE.md (грабли №19).
