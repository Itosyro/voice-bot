# DVIZH Minimal UI v1

Не удаляет функции. Добавляет включённый по умолчанию «Спокойный режим»:

- компактные заголовки и карточки;
- плоский фон без лишних свечений и теней;
- пять основных пунктов в нижнем меню на телефоне;
- «Факты», «Тренировки» и «Соцсети» доступны через `Ещё`;
- второстепенные блоки в «Тренировках» и «Соцсетях» скрыты за кнопкой `Детали`;
- переключатель полного/спокойного вида в настройках;
- настройка хранится локально на каждом устройстве.

Данные, Telegram, расписание, тренировки, Jump Lab и Social Hub не меняются.
